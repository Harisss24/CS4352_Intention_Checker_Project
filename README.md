# Intention Checker

## Overview

Intention Checker is a web-based application developed as part of the **CS 4352 – Human Computer Interaction** semester project at the University of Texas at Dallas.

The application aims to help users develop healthier social media habits by encouraging intentional app usage, providing customizable reminders, and allowing users to reflect on their usage patterns.

The project focuses on reducing mindless scrolling and improving awareness of the difference between intended and actual social media usage.

## Features

### 1. Intention Checker
Allows users to select a reason for opening a social media app and specify their intended usage duration before proceeding.

### 2. Reminder Settings
Allows users to customize app-specific reminders, including reminder frequency and notification preferences.

### 3. Usage History Calendar
Provides an interactive calendar for viewing historical social media usage sessions.

### 4. Session Details & Comparison
Allows users to review their original intentions, compare intended and actual usage durations, and identify usage patterns across sessions.

### 5. Dashboard
Displays usage statistics, recent activity, and navigation to the application's primary features.

## Technologies

- **HTML5** — Page structure and content
- **CSS3** — Styling and responsive layouts
- **JavaScript** — Interactive functionality and data processing
- **localStorage** — Persisting user preferences and intentions
- **GitHub** — Version control and team collaboration
- **Netlify** — Web deployment

The application uses primarily hardcoded sample data for demonstration and usability testing. No backend or database is required.

## Required Usability Tasks

**Simple — Set an Intention for App Usage**

Select a social media app, choose a reason for opening it, specify an intended usage duration, and confirm.

**Moderate — Customize App Usage Reminders**

Navigate to Reminder Settings, select an app, configure reminder frequency and notification preferences, and save changes.

**Complex — Analyze App Usage History**

Navigate to the calendar, select dates, review recorded sessions, compare intended versus actual usage durations, and compare sessions across dates.

## Running the Project

1. Clone the repository:

   `git clone https://github.com/YOUR-USERNAME/intention-checker.git`

2. Open the project folder in VS Code.

3. Open `index.html` using the Live Server extension or another local static web server.

4. Navigate through the application to test its features.

No additional dependencies or installations are required.
